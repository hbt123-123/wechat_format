# 微信聊天记录分析工具

用于分析微信聊天记录JSON文件[chatlog]项目的工具集，支持统计分析、情绪分析等功能。

## 环境要求

- Python 3.8+
- jieba
- pandas
- openpyxl
- openai

安装依赖：
```bash
pip install jieba pandas openpyxl openai
```

## 使用方法

### 1. 运行整合工具（推荐）

```bash
python main.py
```

按提示操作：
1. 输入聊天记录JSON文件路径
2. 选择功能：
   - **1** - 格式化聊天记录JSON文件
   - **2** - 统计分析（语音电话、常用词、消息趋势等）
   - **3** - 情绪分析（需要API配置）
   - **4** - 查看情绪分析结果

### 2. 单独使用各功能脚本

各脚本位于 `d:\porject\微信聊天记录\` 目录下，使用前请修改脚本中的文件路径：

| 脚本 | 功能 |
|------|------|
| `URL下载脚本.py` | 格式化聊天记录 |
| `chat_emotion_analysis.py` | 情绪分析 |
| `语音电话统计.py` | 语音电话统计 |
| `常用词语统计.py` | 常用词语统计 |
| `聊天数最高10日.py` | 聊天数最高10日 |
| `24小时_周_月消息趋势统计.py` | 消息趋势统计 |
| `周_月消息频次统计.py` | 周/月消息频次 |
| `消息月占比统计.py` | 消息月占比 |

## 输入文件格式

原始JSON文件应包含以下字段：
- `time`: 消息时间（ISO格式）
- `isSelf`: 是否自己发送
- `senderName`: 发送者名称
- `type`: 消息类型
- `content`: 消息内容

## 输出文件

- `*_format.json`: 格式化后的聊天记录
- `*_analysis.xlsx`: 统计分析结果（Excel）
- `*_emotion.json`: 情绪分析结果
